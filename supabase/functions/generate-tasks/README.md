# generate-tasks — дневен cron

Генерира задачи за автоматично повтарящите се задължения. Виж
коментарите в `index.ts` и `SPEC.md` §4/§6/§7 за логиката.

## Как да го качиш (през таблото, без CLI)

1. Supabase таблото → ляво меню → **Edge Functions**
2. **Create a new function** → име: `generate-tasks`
3. Изтрий примерния код в редактора, постави съдържанието на
   `index.ts` изцяло, **Deploy**
4. `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` са налични автоматично
   във всяка Edge Function (Supabase ги инжектира сам) — не се налага
   да добавяш секрети ръчно за тази функция.

## Как да го насрочиш да се пуска всеки ден

Supabase Edge Functions → отвори `generate-tasks` → таб **Cron** (или
**Schedule**, според версията на таблото) → добави разписание, напр.:

```
0 2 * * *
```

(02:00 UTC ≈ 04:00–05:00 сутринта в София, спокойно след полунощ —
функцията сама определя "кой ден е днес" по календара на София
отвътре, точният UTC час на тригера не е критичен, стига да е след
полунощ София).

## Проверка, че работи

След първо ръчно изпълнение ("Invoke"/"Test" бутон в таблото, или
изчакай насроченото), провери:

```sql
select * from cron_heartbeats order by ran_at desc limit 5;
select count(*) from tasks;
```

Ако виждаш `status='ok'` ред в `cron_heartbeats` и задачи в `tasks` —
работи. Ако `status='error'`, погледни колоната `details` за причината.
