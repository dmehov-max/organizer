# vat-documents-reminder — напомняне до клиентите за документи

На живо като **`vat-documents-reminder`** (verify_jwt включен). Кодът и
миграциите 0075–0077 са **възстановени на 06.11.2026** от живата
версия в Supabase: били са деплойнати директно на 30.10.2026, без
файлове в репото. Този README е написан по кода, не по оригинална
документация.

## Какво прави

Всеки месец праща до всички активни клиенти до три писма от
**info@mehovconsult.com** с молба да качат документите си за
предходния месец в Controlisy:

| Писмо | Кога | До кого |
|---|---|---|
| 1 | първия работен ден на месеца | всички активни клиенти |
| 2 | 7-о число (или работния ден преди него) | само тези без отговор |
| 3 | 10-о число (или работния ден преди него) | само тези без отговор |

Срокът в писмото е 5-о число (или първият работен ден след него).
Фирмите по ДДС получават по-строг текст; останалите — „с цел по-добра
отчетност“.

Клиентът потвърждава по два начина:
- линк в писмото → `confirm.html?t=<token>` → функция `reminder-confirm`
  („Получих“ / „Качих всичко“ / „Нямам документи“), записва се в
  `client_document_status`;
- отговор на писмото с „Качено“ / „Нямам документи“ → функцията чете
  info@ по IMAP до 15-о число и записва в `client_reminder_replies`.
  Съмнителен отговор („ще кача утре“, въпрос) отива в „Съобщения“ на
  клиента в Органайзера, за да го види човек.

## Режим

В таблица `automation_settings`, ключ `vat_documents_reminder`:

```json
{ "mode": "live" | "test", "test_recipient": "...", "test_limit": 3, "report_recipient": "..." }
```

- `test` — праща до `test_recipient`, най-много `test_limit` писма, с
  „[ТЕСТ]“ в темата. Само в `test` работи `{ "force": true, "stage": N,
  "only": ["Име на фирма"] }` в тялото на заявката.
- `live` — до имейлите на клиентите от досието (`contact_emails`).
- `report_recipient` — получава отчет след всяко пускане с писма или
  грешки.

## Кога се пуска

Cron `vat_documents_reminder_daily`, всеки ден в 06:00 UTC
(`migrations/0075_vat_documents_reminder.sql`). Функцията сама решава
дали днес е ден за писмо; иначе само чете отговорите.

## Secrets

`SMTP_HOST`, `SMTP_USER`, `SMTP_PASSWORD` — пощенският сървър на
домейна (SMTP 465, IMAP 993). Всяко изпратено писмо се копира и в
„Изпратени“ на info@.

## Таблици

- `automation_settings` (0075) — режимът.
- `client_reminders` (0075) — кое писмо до кой клиент е пратено.
- `client_reminder_replies` (0076) — отговорите по имейл.
- `client_document_status` (0077) — токенът за линка и отговорът от
  страницата.
- `0078_client_docs_read_policies.sql` — RLS за четене от таблото.

## Проверка на живо

```sql
select ran_at, status, details from cron_heartbeats
where job_name = 'vat_documents_reminder' order by ran_at desc limit 5;
```
